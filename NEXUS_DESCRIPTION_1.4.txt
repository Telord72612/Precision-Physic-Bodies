[size=6][b]Precision Physic Bodies 1.4 — The Touch API[/b][/size]

[size=4][i]Skyrim VR's NPC collision, rebuilt — and now it can tell other mods what you are touching.[/i][/size]

[color=#000000].[/color]

[size=5][b]What this mod is[/b][/size]

Every NPC in Skyrim has a Havok body: invisible collision capsules and joints. In the base game they
barely matter — they only wake up for a ragdoll death or a shout knockdown, and they were built in
2011 for a flat-screen game where nobody could reach out and touch anything.

In VR you can. And the moment you do, the 2011 body shows: capsules that do not match the woman you
are looking at, joints that sit in the wrong place, a body that reacts like a mannequin.

[b]Precision Physic Bodies rebuilds all of it.[/b] Joints are placed on the actual XP32 skeleton
bones. Capsules are fitted to each NPC's real body mesh — measured at runtime, per NPC, so her
collision matches her body, whatever body mod, preset or weight she is using. About 107 named
capsules per NPC, refitted live as she scales, changes shape, or equips heels.

[color=#000000].[/color]

[size=5][b]★ New in 1.4 — the Touch API[/b][/size]

PPB already knows exactly which capsule your hand is on. As of 1.4 it will [b]tell other mods[/b].

This is a foundation for other authors. On its own the API changes nothing you can see — it is the
plumbing that lets a follower mod, an AI mod, or a reaction mod know that:

[quote][i]the player's left index finger has been resting on her right cheek for 2.4 seconds[/i][/quote]

instead of merely "the player touched her".

[b]Every contact reports:[/b]
[list]
[*][b]Who[/b] — the NPC
[*][b]Where[/b] — at three levels: the region ([i]Face[/i]), the group ([i]In mouth[/i]), and the exact capsule ([i]palate[/i])
[*][b]How deep[/b] — a real distance; negative means inside
[*][b]Which hand[/b] — left and right tracked independently
[*][b]With what[/b] — finger, open palm, fist, HIGGS grab, weapon, or a held object
[*][b]Which weapon[/b] — its name, its class (Sword, Mace, Dagger…) and whether it is blade, blunt or piercing
[*][b]How long[/b] — the contact's duration
[/list]

[b]Weapon contacts come from the game's own physics.[/b] Rather than guessing a blade's shape, PPB
reads Havok's actual contact events — the same ones that make your controller buzz and push her
body. So the capsule your mod is told about is the capsule the engine really hit, and it works the
same for a rapier, an axe, a club or any modded weapon.

[b]Mod authors:[/b] full guide, working code for all three integration paths (Papyrus events,
Papyrus natives, or a C++ SKSE interface), and a spreadsheet of all 107 capsules are on the
[url=https://github.com/Telord72612/Precision-Physic-Bodies]GitHub page[/url]. Start with
INTEGRATION.md.

[size=5][b]Contact logging (for debugging)[/b][/size]

Set [b]contactLog = 1[/b] in [i]SKSE/Plugins/PPB_Skeletons_Added_Race.ini[/i] and every touch is
written to [i]My Games/Skyrim VR/SKSE/PPB.log[/i] — which NPC, which hand, what touched her, the
exact capsule, how deep, and for how long.

If a mod that uses the API is not reacting, this shows in one line whether PPB actually saw the
touch. Verbose by nature, so it ships off; set it back to 0 for normal play.

[size=5][b]Also in 1.4[/b][/size]

[list]
[*][b]Heels fix compatibility.[/b] Heels Fix periodically removes and re-adds its marker spell to check for stuck heels. PPB used to follow that flicker and drop a heeled NPC's collision 8 units below her body. It now reads the persistent offset instead, so the refresh is invisible.
[*][b]Hair and tail push restored.[/b] A registration conflict introduced with the API work was silently stealing the HDT-SMP handshake, which killed hand-pushable hair and weakened tails. Fixed for both Faster HDT-SMP and HDT-SMP Flex.
[*][b]Wigs are no longer reported as tails.[/b] A classification bug filed head-worn garments as tail rigs, so wigs competed against face capsules and could shadow them.
[*][b]Weapon contact accuracy.[/b] Modded weapons whose records carry no bounding data used to be measured from the grip — 40+ units from the blade — and register nothing.
[/list]

[size=5][b]Compatibility[/b][/size]

PPB [b]owns the female skeleton NIF[/b] and must win that conflict — place it high in your load
order, above other skeleton replacers.

[b]Coverage:[/b] PPB drives [b]female NPCs[/b] of mapped races — the human catch-all (which covers
elves, orcs and most custom races), Argonian, Khajiit, Draenei, plus anything you add to
PPB_Skeletons_Added_Race.ini. Males, children and creatures are untouched and keep vanilla
behaviour. Mods consuming the API are told this explicitly so they can fall back.
