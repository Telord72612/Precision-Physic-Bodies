# 1 = collision OFF on all 19 bodies. The 2.1 shipped behaviour: fixes alignment, but nothing can
#     be touched physically during a scene and the engine-narrowphase contact path (src=ENG) stops.
# 2 = MOTION_KEYFRAMED (default, recommended). Three things at once:
#       * NO CONSTRAINT SOLVE, no contacts, no gravity acting on the body. It is moved only by the
#         ragdoll drive, so it converges on the animated pose instead of being dragged off it.
#       * INFINITE MASS -- neither actor can shove the other.
#       * IT KEEPS COLLIDING -- the player can still touch, and the engine-narrowphase contact
#         path (src=ENG) keeps working, which mode 1 loses.

#     bit EVERY FRAME for every active actor (planck_080 main.cpp:4761-4762). So the body follows
#     driveToPose's PD servo (hierarchyGain 0.6 / velocityGain 0.6 / positionGain 0.05):
#     convergent, but LAGGING. And postPhysics writes the ragdoll back into the visible mesh, so a
#     lagging keyframed limb is a lagging VISIBLE limb. See doc 25 section 0b.
#
#     WHAT THIS MEANS IN PRACTICE: mode 2 stops the actors fighting each other, which is what fixes

#  ReDrive v2 -- PER-BONE DRIVE AUTHORITY via the engine's own boneWeights channel (2026-08-28)
# ============================================================================================
# Every ragdoll bone is pulled toward the animated pose by the keyframe controller. Havok
# ships a native per-bone multiplier on that pull: BodyData::m_boneWeights ("The gains are
# multiplied by these weights" -- the Havok 2010 SDK, which is on disk in tools/). PPB sets a
# weight array on the controller immediately before each driveToPose call and restores it
# after, exactly as the SDK's setBoneWeights documentation prescribes.
#

# dead -- the spike test felt identical on both arms because nothing was ever applied. PLANCK
# only READS boneWeights, so v2's weights multiply PLANCK's values instead of racing them.
#
#   < 1   the bone YIELDS -- the pull weakens, contacts win, the arm gives and stays put.
#   = 1   stock. Exactly PLANCK's tuning. DEFAULT FOR ALL 18 -- enabling changes nothing.
